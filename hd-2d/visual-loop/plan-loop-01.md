# Loop 01: 材質の縮尺と、背景を囲う形

開始時の背景内容ID: `3ba9ab2e122d14e0`。利用者のキャラ実験は別セッションで進行中のため対象外。

計画担当の観察では、街・森の広い地面の模様が建物・橋と比べて大きく、模様の反復が画面の主役になっている。森の葉は四角いカードの交差が目立ち、木々の間の地面が大きく空いている。参考の街は石畳と建築の細部が同じ縮尺で読み取れ、森は暗い前景と木立の重なりが通り道を囲っている。洞窟の撮影でも、同じ直方体が並ぶ岩壁、暗すぎる主要通路、中央の大きな黒い門が確認できた。

今回の仮説は「カメラを変えず、広い面の材質を適切な縮尺にし、周縁の形と自然物のまとまりを作ることで、場所としての奥行きと統一感が上がる」。Bloomの強さやオブジェクト数そのものは目標にしない。

実装範囲は `src/maps/{materials,world,definitions}.ts`、必要な背景契約の検証のみ。共通カメラ・プリセット・キャラ・固定コース・採点基準には触れない。

- 街: 石畳の密度と階段・土台の材質縮尺を整え、水際の縁と建築のまとまりで広い平面の反復を分断する。橋と階段を残し、手前の建築や植栽は主経路を隠さない。
- 森: 巨大な草模様を抑え、葉の輪郭を小さな塊に分ける。地面近くの植生と背景の木立をまとめ、橋へ続く道の両岸と遺跡を読み取りやすくする。
- 洞窟: 同じ箱の列に見える岩壁を、連続した岩盤と大小の岩の形に寄せる。環境の間接光を上げて通路と階段を読めるようにし、暖色の灯火・寒色の鉱物の対比を保つ。門の太さ・位置で中央の道を隠さない。

受入条件: 6条件の静止画像が揃うこと、参考・rubric・カメラ等の条件ハッシュが前後一致すること、主要経路の読みやすさや配置の接地を壊さないこと。独立プロセスの各項目の根拠をレビューし、総点上昇だけでは採用しない。描画負荷・HTMLサイズの変化も記録する。
