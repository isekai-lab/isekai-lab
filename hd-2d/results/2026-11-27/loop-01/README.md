- Chrome 158.0.8127.88、ANGLE SwiftShader。PNGは表示中のcanvasをUIだけ隠して撮影。ソフトウェア描画の計測値は実機GPU・スマホ性能を示さない。
- 評価は [rubric-v1.md](../../../visual-loop/rubric-v1.md) の5項目、各0〜4を均等重みで100点換算。参考の出典・ハッシュは [references.json](../../../visual-loop/references.json)。参考画像自体は配布しない。
- `codex-cli 0.171.0-alpha.13.2` を新規・一時・読み取り専用プロセスとして実行。画像と固定基準以外のソース・変更意図・前回得点は渡していない。ログにある項目は `agent_message` のみで、ツール使用なし。CLIは実際のモデル名を報告しなかったため、モデル版の同一性は保証できない。

計画・実装の責任は親の計画担当とTerra実装担当、判定は会話を引き継がないCLIプロセス。OSでソース読出しを禁止する強い隔離ではなく、作業場所・入力と指示を分離した評価である。

## 今回わかった仕組み上の課題

最初に6条件を判定した内容ID `82d129a24ec02e17` は、[candidate-01/](candidate-01/) に保存した。総点は全6条件とも初回基準値から変わらず、平均43.33点だった。森では材質が1→2に上がる一方で道の読みやすさが3→2（同画像再採点も2）、洞窟は道が1→2に上がる一方で個性が2→1に下がった。洞窟の致命的な遮蔽指摘は消えたが、総点横ばいと個性の後退により採用を止め、追加修正へ進めた。`candidate-01.review.json` と `candidate-01.comparison.json` に記録。

追加修正の計画では、点数だけでなく実装と画像の対応を確認した。街の主な階段は上端が地形の内側に大きく入り、踏面の大半が高台の箱に埋まっていた。森の道も高さ0.05固定で高台の下へ消えていた。階段の上端を高台の縁へ揃え、道を実際の地形に沿わせる。洞窟の尖った反復形状は連続した岩盤へ作り直す。

制作途中の内容ID `d761ef6d34cac31a` では地面を外周へ拡張したが、親の画像レビューで却下した。[却下した街の画像](rejected-skirt-town.png)では、無限に続く石畳と途中で途切れる川が不自然に見える。地面の拡張を取り消し、主な家の正面を街路へ向け、橋の歩行帯から屋台を離す修正を加えた。これは制作中の事前レビューであり、却下版に独立採点が付いたという記録ではない。

1. **採点は別プロセスで実現できる**。既存ログインのCodex CLIに複数画像・JSONスキーマを渡し、結果の欠落・範囲外得点・ツール使用を拒否できた。初回はconst/enum項目のtype宣言不足が実APIで検出され、修正と回帰テストを追加した。
2. **撮影の信頼性が先に必要**。canvas要素のスクリーンショットにもDOMの操作パネルは重なる。UIをvisibilityだけで隠し、レイアウト・時刻・カメラを動かさずに撮る方式にした。RenderTarget書き出しとは方式を混ぜない。
3. **重いソフトウェア描画の待機と復旧**。固定35秒の待機ではシェーダー準備・秒単位のフレーム間隔を吸収できなかった。進行段階を確認して待ち、失敗状態を残し、マップごとに成功した画像を保持して再開できる必要がある。実機性能の評価は分離する。
4. **採点基準を同時に最適化しない**。評価項目や参考を変えると点数の連続性が切れる。今回の重みは固定。仕組みの変更は、撮影の不備・実行失敗を直すものに限定した。

## 継続に必要なこと

- 同一画像の再採点を増やし、匿名A/Bで添付順も入れ替える。モデル版を記録・固定する方法を用意し、変更時は対照画像を再採点する。今回のCLIではモデル名が取得できなかった。
- 撮影用の共通APIを統合担当と用意すると、UI操作・不要な再構築への依存を減らせる。ブラウザ版、レンダラ、撮影プロトコルも自動照合へ加える。今回の比較はこれらが同じことを記録から手動確認する。
- 固定6条件の改善に慣れたら、別角度・昼夕などの未使用条件を判定用に保持する。既知の画角だけに合わせた改善を防ぐ。
- 計画用・制作用・判定用の指示を別に版管理し、次の計画へ「得点・見える根拠・失敗分類・採否理由」を渡す。基準の改訂は次のループから適用する。
- 候補ごとのソースを、判定前にコミットまたは単体HTMLとして保存する。今回の却下候補01は画像・判定・内容IDのみ保存し、完全なソーススナップショットは未取得。最終候補02は凍結HTMLをローカル保存し、`candidate-02.bundle.json` にSHA-256と実バイト数を記録した。採用版のソースはこの記録と一緒にコミットする。

実行コマンドは [背景の改善ループ](../../../visual-loop/README.md)。GPGが再ロックした場合は解除を繰り返し求めず、ローカルで評価・改善・検証・コミットまで進める。
