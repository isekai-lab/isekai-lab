# 全画面フィールド探索モック

ソースは `src/main.ts`、`src/field.ts`、`src/style.css`、出力は `../dist/fullscreen-mock.html` です。ルートで `npm run build` を実行すると、外部通信不要の単体HTMLが生成されます。

Canvas 2Dで描く、three-quarter overhead（地面を見下ろしつつ建物正面と人物の顔が見える）形式のフィールド探索モックです。タップ地点へのBFS経路移動、矢印キー/WASD、調査・会話、3地点の切替を試せます。これは場所切替と移動感を確認するためのモックで、既存3作品のゲームルールは統合していません。

背景・建物・人物・樹木はコードから描く新規の手続き的ピクセルアートです。外部画像、他ゲームの画像、第三者素材および第三者素材ライセンスへの依存はありません。コメントはブラウザのローカル保存・表示のみで、外部送信は行いません。
