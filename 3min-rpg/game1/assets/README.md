## 鐘の村のドット絵

`sprites.ts` はこの作品用に自作したピクセル原画です。小屋40×32、図書庫44×32、泉56×24、吊り橋88×24、鐘楼24×40などの原画を、主人公・木と同じ1ドット4pxで描画します。蝶は12×12の羽を開く／閉じる2フレームで、輪郭・触覚・左右の羽を持ちます。地形、小物、布、灯りも共通の `PALETTE` を使います。

原画は文字配列、または座標を指定して文字配列に描き込むコードとして保持しています。Canvasの滑らかな曲線やSVGの拡大で代用せず、輪郭・陰影・屋根瓦・石・横木などを元のピクセル単位で配置しています。拡大時の補間は使いません。

本ファイルの画像アセットはオリジナルで、CC0-1.0として提供します。外部画像・フォント・通信・追加依存は使用していません。共通の主人公・木・パレットの出自とライセンスは `common/assets/LICENSE.md` を参照してください。
